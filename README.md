# ERPNext Stationery Business

A practical ERPNext implementation project for a stationery business.

## Project Overview

This project demonstrates the setup and use of standard ERPNext for managing a stationery business.

The project covers basic business operations across:

- Buying
- Selling
- Stock
- Accounting
- GST

This project uses standard ERPNext features without custom DocTypes, custom fields, or custom code.

## Business

**Company:** BrightDesk Stationery  
**Abbreviation:** BDS  
**Business Type:** Stationery

## ERPNext Configuration

The following standard ERPNext masters and configurations were created:

- Company
- Item Group
- Items
- Warehouses
- Suppliers
- Customers
- Cost Centers
- GST configuration

## Buying Flow

Purchase Order → Purchase Receipt → Purchase Invoice → Payment

## Selling Flow

Quotation → Sales Order → Delivery Note → Sales Invoice → Payment

## Stock Management

Basic stock operations were practiced using:

- Item stock
- Warehouses
- Stock Balance
- Stock Ledger
- Stock movements through buying and selling transactions

## Accounting Understanding

The project includes basic understanding of how ERPNext connects business transactions with accounting entries and stock valuation.
